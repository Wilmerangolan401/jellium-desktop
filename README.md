## 📌 About this application

Jellium-desktop serves as an unofficial desktop client for the Jellyfin media system. This tool provides a dedicated window for your media library on your Windows computer. It removes the need to keep a web browser open while you watch your movies, shows, or listen to music. The application handles the connection to your server and displays your content in a clean interface.

## ⚙️ System requirements

Before you install this software, ensure your computer meets these basic needs:

*   Operating System: Windows 10 or Windows 11.
*   Processor: Standard dual-core processor or better.
*   Memory: 4 gigabytes of RAM.
*   Network: A stable connection to the local network where your Jellyfin server resides.
*   Storage: At least 200 megabytes of free space for the installation files.

## 🚀 Setting up the software

After installation, launch the jellium-desktop app from your desktop shortcut or the Start menu. When the app opens, you will see a request for your server address. 

1.  Enter the URL of your Jellyfin server. This usually looks like http://192.168.1.5:8096 or a local domain name. 
2.  Provide your username and password. 
3.  The application saves these details so you do not need to enter them every time. 
4.  After the connection succeeds, your media library appears on the main screen.

If you cannot connect, check that your server is running and that your computer is on the same network. Ensure you typed the server address correctly.

## 🛠️ Frequently asked questions

**Does this app store my server password?**

The application uses secure local storage to save your login session. It does not send your credentials to any external servers.

**Can I use this without a Jellyfin server?**

No. This software acts as a viewer. You must have a Jellyfin server set up elsewhere to use this client.

**How do I update the application?**

Check the release page periodically. Download the newest installer and run it. The new version replaces the old one.

**Does this support offline playback?**

This release focuses on streaming media from your server. Offline playback features might arrive in future updates.

## 📖 Using the interface

The interface mimics common media player designs. Browse your library using the navigation menu on the left side of the window. Click on any item to view its details, such as the production year, runtime, and plot summary. Press the play button to start your content. The playback controls allow you to pause, skip, or adjust the volume. You can toggle full-screen mode by clicking the icon in the corner of the player window.

## 🛡️ Privacy and security

The jellium-desktop project prioritizes user privacy. Data communication occurs directly between your computer and your Jellyfin server. The app does not track your usage habits or share your media library information with third parties. All traffic remains within your local network.

## 🤝 Troubleshooting

If the application crashes or fails to play a file, try these steps:

*   Restart the application.
*   Refresh the page within the app.
*   Verify that your server permissions allow access to the specific folders.
*   Check the Windows firewall settings to ensure the application has network access.

If the issue persists, gather information about your version number and the specific error message. This helps in understanding the source of a problem.
